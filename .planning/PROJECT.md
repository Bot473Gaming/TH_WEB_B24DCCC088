# Quản lý khóa học trực tuyến

**Objective:** Xây dựng module "Quản lý khóa học online" trên nền tảng `base-web-umi` hiện có.

**Success Criteria:**
- Ứng dụng chạy ổn định, đủ các chức năng quản lý danh sách, thêm, sửa, xóa khóa học.
- Dữ liệu được lưu trữ và cập nhật thành công xuống `localStorage`.
- Giao diện trực quan, dễ sử dụng, phân chia menu rõ ràng.
- Sử dụng đúng cấu trúc base (`models`, `services`, `pages`), các thành phần giao diện hiện có của Ant Design.

**Architecture & UI:**
- Khung giao diện: Duy trì kiến trúc Ant Design 4 hiện tại (Legacy).
- Ngôn ngữ: TypeScript.
- State Management: Umi `useModel`.
